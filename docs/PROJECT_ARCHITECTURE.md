# Project Map & Architecture — CS-Breaker

## 1. System Architecture & Folder Layout (Kedro 8-Layer + DVC)

The repository follows the **Kedro 8-Layer Data Engineering Hierarchy** (`data/01_raw` through `data/08_reporting`) orchestrated by **DVC (`dvc.yaml`)** and configured via declarative catalogs (`conf/base/{catalog.yml,parameters.yml}`). Detailed dataset provenance, schema specifications, and checksum guarantees are documented in **[DATA_CATALOG.md](DATA_CATALOG.md)** and **[MODEL_CATALOG.md](MODEL_CATALOG.md)**.

```text
cs-breaker/
├── dvc.yaml                          # 5-stage DVC DAG pipeline (dvc repro / dvc metrics show)
├── pyproject.toml                    # PEP 621 package metadata & Kedro project config
├── conf/
│   └── base/
│       ├── catalog.yml               # Declarative Kedro Data Catalog (dataset paths & SHA-256 pins)
│       └── parameters.yml            # Hyperparameter registry (shrinkage alphas, risk guards, Kelly)
├── data/                             # Kedro 8-Layer Data Engineering Hierarchy
│   ├── 01_raw/                       # Immutable raw match sources (Kaggle, HLTV, StrandedPond, OpenCS2)
│   ├── 02_intermediate/              # Parsed & typed lineup snapshots
│   ├── 03_primary/                   # Canonical master matches consolidated
│   ├── 04_feature/                   # Pre-match feature tables & multi-system player rankings

│   ├── analysis/

│   │   ├── betting_guards_a_to_d.py  # Guard B (logit gate), Shin devigging, Guard W (DRO)
```

## 2. Active Model & Decision-Time Strategy Stack

### 2.1 Nomenclature & Architecture Mapping

| Canonical Architecture Name | Short Code | Domain Role & Performance |
|---|---|---|
| **`Bayesian-Score-Ridge-Challenger`** | **`Challenger-Bayes`** | 16 dynamic Bayesian strength channels with Gaussian uncertainty, random-walk/mean-reverting dynamics, and stopped-series likelihood. Development Log Loss: **0.624766** vs. Incumbent 0.625585. |
| **`Ratings-Form-Ridge-Incumbent`** | **`EXP-Ridge`** | `ridge_C1_ratings_form_hnone`: Ridge combination of historical multi-system ratings (TrueSkill, Glicko-2, OpenSkill) and recent 20-series team form. |
| **`Player-Archive-Elo-Blend`** | **`Blend-Player`** | 50/50 blend of player-level map Elo and organization series Elo. TEST Log Loss: 0.640090. |
| **`Series-Elo-Baseline`** | **`Baseline-Elo`** | Zero-dependency retrospective team-name Elo baseline ($K=32$, 400-point scale). TEST Log Loss: **0.666036**, Accuracy 59.79%. |
| **`Market-Shrunk-Hybrid-50`** | **`Hybrid-50`** | 50/50 logit-space Bayesian shrinkage combining model prediction with 2-way Shin de-vigged bookmaker consensus: `logit(p_hybrid) = 0.50 * logit(p_model) + 0.50 * logit(q_shin)`. |

### 2.2 Decision-Time Safety Gates & Risk Parameters

| Safety Gate / Parameter | Formula / Threshold | Domain Purpose |
|---|---|---|
| **`Market-Divergence-Gate`** *(Guard B)* | `\|logit(p_model) - logit(q_market)\| <= 0.85` | Dynamic logit bound; rejects severe divergence where model overconfidence occurs. |
| **`Model-Consensus-Veto`** | `\|p_challenger - p_baseline\| <= 0.10` | Cross-architecture consensus veto; suppresses false edges when complex models diverge from simple form. |
| **`Wasserstein-Robust-Gate`** *(Guard W)* | `epsilon = 0.025` | Distributionally robust optimization; ensures non-negative EV under distribution shifts: `(p_hybrid - 0.025) * (1 - tax) * O - 1 > 0`. |
| **`Optimal Synergy Staking`** | **1/4 Kelly** | 1/4 Kelly under 12% Polish turnover tax or 0% International tax, bounded by `EV_net in [5%, 25%]`, `Odds <= 4.00`, and strict 150 PLN cap per bet. |

## 3. Running the Simulation Pipeline

```bash
# Run full 5-stage simulation pipeline end-to-end
.venv/bin/python scripts/run_simulation_pipeline.py --stage all

# Or run specific stages
.venv/bin/python scripts/run_simulation_pipeline.py --stage verify_inputs
.venv/bin/python scripts/run_simulation_pipeline.py --stage model_benchmark
.venv/bin/python scripts/run_simulation_pipeline.py --stage betting_simulation
.venv/bin/python scripts/run_simulation_pipeline.py --stage econometric_audit
.venv/bin/python scripts/run_simulation_pipeline.py --stage generate_report

# Run standard walk-forward model benchmark CLI
.venv/bin/python scripts/run_model_benchmark.py
```
